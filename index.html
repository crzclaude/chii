권장 집행내역 열

지출일자, 세부사업, 통계목, 지출내용, 지출금액, 지급명령번호
기관별 열 이름이 다를 수 있어 자동 탐지 후 결과를 확인해야 합니다.

보안 안내: 업로드된 파일은 이 페이지 내부 메모리에서만 사용됩니다. 새로고침 시 파일 데이터는 사라집니다. 공공기관 보안 규정에 따라 사용 여부를 확인하세요.

선택한 부기의 사업·통계목만

거래 내용에 여러 규칙이 동시에 매칭되면 미분류 처리합니다. 담당자가 바꾼 거래는 자동 재분류 시에도 유지됩니다.

데이터 검증 리포트

실무 사용 전 확인할 문제를 자동으로 점검합니다.

통계목별 합계 대조

업로드된 건별 집행내역의 합계와 부기별 분류 금액을 비교합니다. e호조 화면의 공식 잔액과의 대조는 별도로 필요합니다.
